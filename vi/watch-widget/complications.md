# Complications

StressMonitor có complication ở nhiều kích thước để hợp với các mặt đồng hồ khác nhau.

## Các kích thước complication

| Kích thước | Hiển thị |
|------|---------|
| Graphic Corner | Vòng cung màu căng thẳng + nhãn cấp độ |
| Graphic Circular | Vòng màu căng thẳng kèm biểu tượng |
| Graphic Bezel | Thước đo căng thẳng toàn chiều rộng |
| Modular Small | Chỉ báo màu + con số |
| Modular Large | Nhãn căng thẳng + thời gian cập nhật gần nhất |
| Utilitarian Small | Biểu tượng căng thẳng tối giản |

## Mỗi complication hiển thị gì

Mọi complication đều hiển thị:
- **Mức căng thẳng hiện tại** (theo màu: xanh lá / xanh dương / vàng / đỏ)
- **Nhãn phân loại căng thẳng** (Xuất sắc / Bình thường / Cần chú ý / Quá tải)

Complication cỡ lớn hiển thị thêm:
- Thời gian đo gần nhất
- Điểm căng thẳng dạng số (0–100)

## Mã màu

| Màu | Phân loại |
|-------|----------|
| 🟢 Xanh lá | Trạng thái xuất sắc |
| 🔵 Xanh dương | Trạng thái bình thường |
| 🟡 Vàng | Cần chú ý |
| 🔴 Đỏ | Quá tải áp lực |
